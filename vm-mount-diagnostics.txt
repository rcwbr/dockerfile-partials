Commands to run for diagnostics:

--- ON YOUR MAC ---

1. Find QEMU process and show fsdev arguments:
   ps aux | grep qemu | grep -v grep
   ps aux | grep qemu | grep -oE 'fsdev[^ ]*'
   ps aux | grep qemu | grep -oE 'mount_tag=[^,]*'

2. Check config.plist:
   plutil -p "$(find ~/Library/Containers/com.utmapp.UTM/Data/Documents/container-workspace-utm-vm.utm -name config.plist)" | grep -E 'Shares|QEMU|fsdev|mount_tag|AdditionalArguments'

3. Check if shared directories exist in the sandbox:
   ls -la ~/Library/Containers/com.utmapp.UTM/Data/Documents/container-workspace-utm-vm.utm/Data/

--- IN THE VM ---

1. Check virtio devices and their types:
   for dev in /sys/bus/virtio/devices/*; do
       echo "$(basename $dev): type=$(cat $dev/type), tag=$(cat $dev/mount_tag 2>/dev/null)"
   done

2. Try mounting with different options:
   sudo mkdir -p /mnt/container-workspace
   sudo mount -t virtiofs share /mnt/container-workspace -o cache=always 2>&1
   sudo mount -t 9p share /mnt/container-workspace -o trans=virtio 2>&1

3. Check if the virtiofs module is properly loaded:
   lsmod | grep virtiofs
   sudo modprobe virtio_fs 2>&1 || true
